# Terminal Portfolio

Portafolio web personal interactivo con estética y experiencia de terminal Unix / CLI. Desarrollado con tecnologías web puras (Vanilla) e integración backend en PHP.

---

## Stack Tecnológico

* **Frontend:** HTML5 Semántico, CSS3 Puro (Flexbox / Grid), JavaScript Vanilla (ES6+).
* **Backend:** PHP (Manejo de peticiones y formularios).
* **Base de Datos:** PostgreSQL.

---

## Características

* **Diseño CLI / Terminal:** Estética inspirada en editores de código y consolas bash/zsh.
* **Semántica HTML5 estricta:** Estructura accesible y limpia sin frameworks.
* **Soporte Bilingüe:** Alternancia rápida entre Español e Inglés.
* **Formulario de Contacto:** Procesamiento y persistencia en backend mediante peticiones HTTP.
* **Preparado para Escalar:** Arquitectura pensada para migración futura a Laravel + React.

---

## Ejecución en Local

### Requisitos previos
* PHP 8.x instalado localmente (o un entorno tipo XAMPP / Laragon).
* Servidor PostgreSQL (opcional para la etapa con base de datos).

### Pasos para clonar y correr el proyecto

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/portfolio.git](https://github.com/tu-usuario/portfolio.git)
   cd portfolio
   ```

2. **Iniciar el servidor embebido de PHP:**
  ```bash
  php -S localhost:8000

  ```

3. **Abrir en el navegador:**
Acceder a `http://localhost:8000`.
